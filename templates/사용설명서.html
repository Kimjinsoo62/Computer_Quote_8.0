1. 프로그램 시작과 종료

시작하기

프로그램 폴더의 START.bat 을 더블클릭합니다. 검은 명령창이 뜨며 서버가 구동되고, 잠시 후 주소창 없는 전용 창(App 모드)으로 메인 화면이 자동 실행됩니다.

  • 검은 명령창은 백엔드 서버가 구동 중인 창입니다. 프로그램을 사용하는 동안에는 닫지 마세요.
  • 실행 시 콘솔 창에 Local: http://127.0.0.1:8090/ 및 Network: http://[이 PC의 IP]:8090/ 주소가 함께 출력됩니다.
  • 전용 창은 독립 프로필로 실행되므로 개인 브라우저의 쿠키나 확장 프로그램과 충돌하지 않습니다.
  • Excel 견적서·작업내역서 생성, Apple CTO 옵션 불러오기, 중고 시세 검색, 업데이트 대기처럼 시간이 걸리는 작업은 화면 우측 하단의 작은 처리 상태 창에 진행 상황이 표시됩니다.
  • PC에 처음 설치하는 환경이라면 START.bat 이 필요한 패키지가 없음을 감지하고 install.bat 을 자동으로 실행합니다. 직접 install.bat 을 먼저 실행해도 됩니다.

종료하기

방법동작 및 권장 상황
화면 우측 상단 ✕ 종료 누르면 확인 없이 바로 임시 캐시 정리 → 화면 새로고침 → 서버 프로세스 종료 · 8090 포트 반환 → 앱 창 닫기를 일괄 수행합니다. 가장 안전한 권장 방법입니다.
🔄 업데이트 GitHub에 새 버전이 있는지 확인해 팝업으로 알려 줍니다(없으면 "최신 버전"). 변경 목록을 보고 승인하면 내려받아(git pull) 프로젝트를 갱신하고, 완료 후 재시작 여부를 묻습니다. 재시작을 누르면 구성요소를 확인한 뒤 서버가 다시 켜지고 화면이 자동으로 새로고침됩니다. 이 PC에서 프로그램 파일을 직접 수정했다면 업데이트가 실패할 수 있습니다. GitHub 저장소 이름이 바뀐 경우(예: Computer_Quote_9.0 → Computer_Quote_X.15)에도 업데이트 시 저장소 주소가 자동으로 새 이름으로 바뀝니다.
update.bat 화면을 열 수 없을 때 직접 실행하는 수동 업데이트입니다. 서버를 끄고 GitHub에서 내려받은 뒤 구성요소를 확인하고 다시 시작합니다. 내려받기 전에 저장소 주소가 예전 이름(Computer_Quote_9.0)이면 새 이름(Computer_Quote_X.15)으로 자동으로 바꿉니다(콘솔에 "Repository renamed" 표시).
stop.bat 화면이 멈추거나 창이 닫힌 뒤에도 백그라운드 프로세스가 남아있을 때 실행합니다. 서버 종료, 8090·8091 포트 정리, 앱 전용 브라우저 창 닫기, Python 캐시 삭제를 수행합니다.
force_stop.bat 포트 점유가 풀리지 않거나 프로세스가 강제 정지되지 않을 때 쓰는 비상용입니다. 실행하면 스스로 관리자 권한을 요청합니다.

2. 네트워크(LAN) 접속 — 다른 PC · 태블릿에서 작업하기

본 프로그램은 0.0.0.0 바인딩을 지원하여, 프로그램을 실행한 메인 컴퓨터뿐만 아니라 같은 공유기(와이파이 또는 유선 LAN)에 연결된 사무실/매장의 모든 기기에서 동시 접속해 작업할 수 있습니다.

접속 주소 확인 및 복사

  1. 메인 프로그램 상단 메뉴 바를 보면 🌐 네트워크 접속 (192.168.x.x) 버튼이 있습니다. 괄호 안에 현재 실행 중인 PC의 공유기 내부 IP가 실시간으로 표시됩니다.
  2. 이 버튼을 클릭하면 접속 안내 창이 열립니다. 네트워크 주소(예: http://192.168.0.13:8090/)와 이 PC 전용 주소(http://127.0.0.1:8090/) 옆의 📋 복사 버튼으로 주소를 클립보드에 복사합니다.
  3. 같은 사무실 내의 다른 직원 PC, 상담용 노트북, 카운터 태블릿(아이패드/갤럭시탭), 스마트폰의 웹 브라우저(Chrome, Edge, Safari 등)를 열고 복사한 주소를 입력합니다.
동시 다중 작업 지원: 다른 기기에서도 실시간 견적 조회, 마진 및 옵션 조절, 엑셀 견적서 다운로드, 컴퓨터 작업내역서 작성 및 서버 저장을 메인 PC와 동일하게 이용할 수 있습니다.
다른 기기에서 쓸 때 주의:
  • 🧮 계산기는 누른 기기가 아니라 서버 PC 화면에 열립니다.
  • ✕ 종료와 🔄 업데이트는 서버 자체를 끄거나 재시작하므로, 어느 기기에서 누르든 모든 기기의 접속이 끊깁니다.
접속이 안 될 때 확인 사항:
  • 다른 컴퓨터나 모바일 기기가 동일한 공유기(Wi-Fi 또는 유선 네트워크)에 연결되어 있는지 확인하세요. (외부 LTE/5G 접속 불가)
  • 윈도우 방화벽 알림이 떴을 때 '액세스 허용'을 눌렀는지 확인하고, 연결이 안 된다면 윈도우 방화벽 인바운드 규칙에서 8090 포트(TCP)를 허용해 주세요.

Apple Store 카테고리

MacBook · iMac · Mac mini · Mac Studio · iPad & iPhone · 주변기기 & Care+ · Apple 전제품 통합 카테고리를 제공합니다. 애플 공식 홈페이지의 판매가와 라인업을 실시간으로 가져옵니다. Apple Store 탭을 누르면 MacBook이 자동으로 표시됩니다. Apple 견적은 사양 중심이라 부품 단가가 -로 표시되며, 초기 세팅비만 단가가 표시됩니다.

카드 표시 및 기능

  • 가격 출처 배지:
    • ● 실시간 수집 — 방금 컴퓨존/애플 공식몰에서 가져온 최신 판매가
    • ● Apple 공식몰 + CTO — 애플 공홈 라이브 가격에 사용자 맞춤 옵션이 합산된 금액
    • ● Apple 공식몰 현재 판매가 — 애플 공식 스토어 라이브 판매가
    • ● Apple 공식몰 스냅샷 — 공식몰 접속에 실패해 마지막으로 저장된 가격을 보여 주는 경우
    • ● 기본가/캐시 — 실시간 수집값이 아닌 기본가 또는 저장된 값 (노트북 검색 결과는 항상 이 배지로 표시)
  • 상품상세 / 구입하기: 카드의 🛍️ 상품상세 ↗(컴퓨존) 또는 🛍️ 구입하기 ↗(Apple) 버튼으로 판매 페이지를 엽니다.
  • 🖼️ 이미지: 카드 원본 페이지(컴퓨존 상품상세 · Apple 구매 페이지)의 대표 이미지를 새 창으로 엽니다. 컴퓨존은 해당 상품 사진, Apple은 제품군 대표 사진입니다. 같은 이미지가 화면 아래 상세 견적서 하단에도 작게(높이 200px) 표시되며, 누르면 원본 크기로 열립니다. 이 이미지는 화면 전용이라 Excel 견적서에는 들어가지 않습니다.
  • 리스트로 보기: 견적 카드 영역 상단의 '리스트로보기' 버튼을 누르면 구분 · 모델명 · CPU · 그래픽 · 금액이 담긴 컴팩트한 목록으로 전환됩니다. 목록의 행을 클릭하면 상세가 바뀌며, '카드로보기'로 되돌릴 수 있습니다.

5. 견적 옵션 (모니터 · 키보드 · 메모리 · 세팅비 · 단가표시 · 마진)

견적 상단 바 우측의 버튼을 통해 고객의 요구사항에 맞게 품목을 즉시 추가하거나 제외할 수 있습니다. 버튼에 모니터 (포함됨), 모니터 (제외됨) 처럼 현재 상태가 직관적으로 표기됩니다.

옵션 버튼동작 및 적용 대상기본 설정
🖥️ 모니터컴퓨존 견적에 모니터를 추가합니다. 금액은 견적 정보에서 수정 가능합니다.제외 (기본 180,000원)
⌨️ 무선키보드무선 키보드+마우스 세트를 추가합니다.제외 (기본 30,000원)
🧠 메모리32GB로 추가기본 16GB 메모리를 32GB(듀얼채널)로 업그레이드합니다. (AI PC 전용)제외
🛠️ 초기 세팅비컴퓨존 및 Mac 제품군에 OS/프로그램 세팅비를 추가합니다.제외 (기본 0원, 별도청구)
💰 단가표시 / 단가미표시견적서의 개별 부품 단가를 공개할지, 아니면 숨기고 합계금액만 표시할지 결정합니다.초록색 (단가표시)

💳 마진 순환 버튼

상단 견적 정보 버튼 오른쪽에 위치한 💳 마진 버튼을 클릭할 때마다 아래 순서대로 실시간 변경됩니다:

C (30% 소비자견적) → 25% → 20% → 15% → 10% → 0% (원가견적) → 다시 C
  • 부품 단가 비례 분배: 마진율을 바꾸면 총액뿐만 아니라 모든 부품의 단가에도 동일한 마진이 자동 반영되어 출력됩니다.
  • 만원 단위 올림: 마진이 적용된 견적은 만원 단위로 올림 처리되며, 부품 단가 합과의 차액은 번들할인 행으로 정밀 보정되어 합계가 완벽히 일치합니다. 0% 원가견적은 컴퓨존 판매가 원 단위 그대로 출력됩니다.

6. 게임으로 PC 찾기

🎮 게임으로PC찾기 버튼을 누르면 2단계 추천 위자드가 열립니다.

  1. 게임 선택: 플레이하려는 대표 게임(롤, 배그, 로스트아크, 디아블로, 발로란트 등)을 최대 4개까지 선택합니다.
  2. 해상도 선택: 모니터 환경(FHD, QHD, 4K UHD)을 선택합니다.
  3. 나에게 딱맞는 PC보기를 누르면 쾌적한 플레이를 보장하는 최적 사양의 조립PC 견적 카드가 추천됩니다.

7. 금액대로 찾기 (조립PC · 노트북)

💵 조립PC 금액대로 찾기 또는 💻 노트북 금액대로 찾기 버튼을 누르면 상단에 금액 입력 바가 나타납니다. 팝업 창 이동 없이 현재 화면에서 바로 검색할 수 있습니다.

  1. 최저가와 최고가를 만원 단위(예: 70 ~ 100)로 입력합니다. 입력 시 원화 금액(= 700,000원)이 바로 표시됩니다.
  2. 검색 버튼(또는 Enter)을 누르면 예산에 맞는 구성을 가격 낮은 순 상위 10건 추출하고, "총 N건 중 금액 낮은 순 10건"으로 결과 수를 알려 줍니다.
    • 조립PC: 컴퓨존 추천조립PC · 아이웍스PC · 프리미엄PC에서 검색합니다. (AI PC는 제외)
    • 노트북: 컴퓨존 노트북에서 검색합니다. 노트북 결과는 부품 구성표가 없고, 모니터 · 키보드 · 세팅비 옵션이 적용되지 않으므로 해당 버튼이 숨겨집니다.

8. Apple Store 공식몰 실시간 동기화 & CTO 맞춤 구성

공식몰 라이브 수집

과거 프로그램에 내장되어 있던 하드코딩 모델은 제거했습니다. 애플 공식 홈페이지(한국)에서 현재 판매 중인 라인업을 실시간으로 수집해 보여 줍니다. 공식몰 접속에 실패하면 마지막으로 저장된 스냅샷(apple_catalog_cache.json)을 대신 보여 주며, 카드에 ● Apple 공식몰 스냅샷 배지가 붙습니다.

🔄 공홈 실시간 새로고침 버튼

애플스토어 탭 선택 시 카테고리 우측 끝에 🔄 공홈 실시간 새로고침 버튼이 제공됩니다. 신제품 발표나 가격 변동이 있을 때 누르면, 현재 카테고리의 메모리 캐시를 비우고 애플 공식몰에서 다시 가져옵니다. (실패 대비용 스냅샷 파일은 유지됩니다.)

⚙️ 사양 CTO 맞춤 구성

맞춤 옵션이 있는 Apple 제품에는 카드 하단에 ⚙️ 사양 CTO 수정 버튼이, 상세 견적서에 ⚙️ 옵션 업그레이드 버튼이 표시됩니다. 누르면 맞춤 옵션 창이 열립니다.

  • Mac (MacBook Air/Pro, iMac, Mac mini, Mac Studio): 애플 공식몰 '구성하기'와 같은 가격으로 계산합니다. 옵션을 바꿀 때마다 공식몰에 다시 물어 총액을 받으므로, 칩을 바꾸면 메모리·SSD 기본값과 가격도 공식몰과 똑같이 바뀝니다. 선택 가능한 항목은 제품마다 다르며 프로세서, 통합 메모리, 저장장치, 디스플레이 마감(Nano-texture), 이더넷, 전원 어댑터 등입니다. 재고가 없는 옵션은 표시되지 않습니다. (선택 시 계산)으로 표시된 옵션은 고르면 다른 구성도 함께 바뀌는 옵션입니다(예: MacBook Air 13 30W 모델에서 메모리를 올리면 35W 어댑터로 바뀜). 고른 뒤 공식몰 가격으로 다시 계산됩니다.
  • MacBook Neo, iPad, iPhone, 디스플레이: 구매 페이지에 있는 완제품끼리의 가격 차이로 옵션(저장장치, 연결 등)을 만듭니다.
  • 💾 CTO 구성 적용을 누르면 카드와 상세 견적서에 반영됩니다. 메모리·SSD·칩을 바꾸면 견적서의 기본 사양 행이 바뀐 사양으로 교체되고 추가 금액이 그 행에 더해집니다(예: 16GB → 24GB 통합 메모리 340,000원). 칩을 바꿔 함께 올라간 메모리·SSD는 금액 0원으로 사양만 바뀌며, 이더넷·나노 텍스처·전원 어댑터처럼 기본 행이 없는 항목은 아래에 새 행으로 붙습니다. 🔄 기본 사양 복원으로 되돌리거나 취소로 닫을 수 있고, 다시 열면 적용한 선택이 그대로 보입니다. AppleCare+는 CTO 창에 없습니다.
  • 적용한 CTO는 📥 Excel 다운로드(전체)와 카드별 📥 엑셀 견적서에도 추가 품목 행과 합계로 반영됩니다. 초기 세팅비 버튼을 바꿔도 유지되며, 카테고리 버튼을 다시 누르면 기본 사양으로 새로 불러옵니다.

정품 단가 그대로 적용 (올림/반올림 없음)

Apple Store 제품의 단가 및 총 견적 금액은 어떠한 올림이나 반올림도 적용하지 않고, 애플 공식 홈페이지에 공시된 실제 원단위 판매가 그대로 정확하게 표시되며, Excel 견적서에도 동일하게 공홈 가격 그대로 반영됩니다.

⚠️ 공식몰 수집 상태 점검

애플 공식몰이 페이지를 개편하면 일부 제품이나 옵션을 못 읽을 수 있습니다. 이때 결과 위에 노란색 ⚠️ Apple 공식몰 수집 상태 점검 상자가 나타나 무엇이 잘못됐는지 알려 줍니다(✕로 닫기). 같은 내용이 서버 명령창 로그에도 남습니다.

  • 제품군을 읽지 못함: 해당 제품(예: macbook-air)이 목록에서 빠졌습니다. 페이지 구조 변경이 의심됩니다.
  • 모델 수가 크게 줄어듦: 직전보다 30% 넘게 줄었습니다. 실제 단종이 아니라면 구조 변경을 확인하세요.
  • 구성하기(CTO) API 응답 없음 / 주소를 찾지 못함: Mac 맞춤 구성이 비교 방식으로 돌아가고, 기본 메모리·SSD 표기가 최소 용량으로 보일 수 있습니다.
  • 마지막 저장 데이터 표시: 공식몰 접속에 실패해 이전에 저장한 목록을 보여 줍니다. 인터넷 연결을 먼저 확인하세요.
  • 새 제품군 발견: 공식몰에 새 제품군(예: Mac Pro)이 생겼지만 어느 카테고리에도 속하지 않아 표시되지 않습니다. 개발자에게 카테고리 추가를 요청하세요.

구매 페이지가 소개 페이지로 넘어가는 예전 링크(예: 단종된 iPad 10.2)는 정상으로 보고 경고하지 않습니다.

9. 중고 시세 검색 (번개장터 · 중고나라 연동)

신품 견적을 상담할 때 고객이 기존 중고 시세를 묻거나 예산 비교를 원할 경우, 번거롭게 검색창을 켤 필요 없이 카드에서 원클릭으로 중고 시세를 비교할 수 있습니다.

  • 각 견적 카드 하단에 ⚡ 번개장터 및 🟢 중고나라 버튼이 배치되어 있습니다.
  • 조립PC 스마트 검색어 변환: 중고 장터에는 '아이웍스-0225' 같은 유통사 모델명이 등록되지 않습니다. 본 프로그램은 PC 견적 분석 엔진을 통해 핵심 부품인 CPU + 그래픽카드(예: 7800X3D RTX 4070 SUPER, i5 14400F RTX 4060)로 검색어를 스마트하게 자동 조합하여 실제 거래 게시글만 콕 집어 열어 줍니다.
  • Apple 정품 검색: 애플 제품은 중고 장터에서 많이 쓰는 한글 제품명과 핵심 사양(예: 맥북 에어 13 M5)으로 변환해 검색합니다.

10. 견적 정보 등록 (닫기 버튼 · 저장 후 깜빡임 중지)

Excel 견적서에 자동 인쇄될 견적처(고객) 정보, 공급자(매장) 정보, 그리고 추가 부품 단가를 설정합니다. 상단 바의 📇 견적 정보 버튼을 누르세요.

개선된 핵심 기능

  • ✨ 저장 후 깜빡임 자동 정지: 프로그램 실행 직후 입력을 안내하기 위해 깜빡이던 📇 견적 정보 버튼은, 내용을 입력하고 💾 저장을 누르면 즉시 깜빡임을 멈추고 일반 버튼으로 고정됩니다.
  • 🔴 선명한 빨간색 [닫기] 버튼: 다크모드에서 잘 보이지 않던 모달 우측 상단 ✕ 대신, 눈에 확 들어오는 빨간색 ✕ 닫기 버튼을 배치하여 언제든 간편하게 닫을 수 있습니다. (Esc 키로도 닫기 가능)
구분항목설명 및 특징
견적처상호명, 대표/담당자, 주소, 연락처, 이메일, 견적일견적일을 비워 두면 엑셀 다운로드 당일 날짜가 자동 입력됩니다.
공급자상호명, 대표/담당자, 주소, 연락처, 이메일한 번 저장하면 영구 보존되어 매번 입력할 필요가 없습니다.
추가 품목 금액모니터, 키보드마우스, 초기 세팅비 기본 단가기본값을 매장 정책에 맞게 자유롭게 수정할 수 있습니다. 0원으로 설정 시 '별도청구'로 표기됩니다.
  • 견적처·공급자에 기본 예시 데이터(대한민국주식회사 등)가 남아 있으면 창 상단에 ⚠️ 경고가 표시됩니다.
  • 💾 저장하면 작업내역서의 업체·고객 정보에도 함께 채워지고, 📋 작업내역서 버튼의 깜빡임도 멈춥니다.
  • 🗑 삭제(초기화)는 확인 후 저장된 정보를 모두 지웁니다.

11. Excel 견적서 다운로드 (전체 및 카드별)

두 가지 방식으로 엑셀 파일을 내려받을 수 있습니다.

다운로드 버튼위치내용 및 용도
📥 Excel 다운로드 상단 견적 바 좌측 현재 카테고리의 모든 견적을 1개의 엑셀 파일로 일괄 다운로드 (견적요약 시트 + 전체 폼 포함, 비교 제안용)
📥 엑셀 견적서 각 견적 카드 하단 해당 제품 단 1건만 깔끔하게 담긴 맞춤형 엑셀 견적서 다운로드 (고객 단일 발송용)
스마트 파일명: 파일 이름만 보고도 내용을 알 수 있도록 카테고리, (카드별이면) 구분·모델명, 제외된 옵션(모니터제외 · 무선키보드제외 · 초기세팅비제외), 메모리32GB, 마진 구분, 단가미표시 여부, 견적일이 자동 조합됩니다. 포함된 옵션은 파일명에 적지 않습니다.
예: 입문형_아이웍스X-0216_오늘의견적_모니터제외_무선키보드제외_초기세팅비제외_소비자견적_2026-10-08.xlsx

12. Excel 견적서 구성과 인쇄 (8종 서식 완비)

생성된 엑셀 파일에는 다양한 업무 환경에 즉시 활용할 수 있도록 서로 다른 전문 디자인의 견적서 양식 8종이 각각의 시트로 완비되어 있습니다.

시트명스타일 및 추천 용도
견적요약전체 견적을 한눈에 비교하는 마스터 요약표 (모델명, 상품번호, 견적금액, 정품링크)
폼1 (표준)가장 널리 쓰이는 정통 B2B 표준 견적서 (공급자/공급받는자 직인란 완비)
폼2 (인보이스)글로벌 비즈니스 및 영문 제출용 모던 INVOICE 스타일
폼3 (보고서)사내 결재 및 기업 제안용 총액 강조 요약 보고서형
폼4 (명세서)부품 규격 및 상세 모델명이 일목요연하게 정리된 엔지니어링 기술 명세서형
폼5 (리테일)매장 즉시 발송 및 간이 확인용 심플 영수증 스타일
폼6 (조립PC)부품별 무상 A/S 기간과 4대 소비자 유의사항이 명시된 조립PC 실무 전용 견적서
폼7 (데스크탑)상단 사업자 정보와 하단 정밀 제품 SPEC / 고객 발주확인란이 포함된 제안형 서식
폼8 (클래식)공급자 등록번호 세로형 관공서/기업 납품 전통 서식 (첨부사항 및 특약란 구비)

인쇄 최적화 보장

  • 모든 시트는 A4 세로 1페이지 폭 맞춤(Fit to Page Width)과 좌우 여백 15mm(위아래 약 25mm)가 사전 세팅되어 있어, 엑셀에서 바로 인쇄하거나 PDF로 저장해도 우측 열이 잘리지 않습니다.
  • 모든 금액은 VAT(부가가치세) 포함 기준입니다. 견적 유효기간은 견적요약 · 폼1~5에 '▶ 견적유효기간 : 견적일로부터 24시간', 폼6에 발행일로부터 3일, 폼8에 견적일로부터 7일로 표기됩니다.

13. 컴퓨터 작업내역서 (출장/수리 작성 · 저장 · 인쇄 · 엑셀)

매장 방문 고객이나 출장 A/S 시 컴퓨터 점검/수리/부품교체/공임 내역을 웹에서 간편히 작성하고, 종이 출력 · PDF 저장 · 엑셀 다운로드 · 서버 DB 보관까지 처리하는 현장 업무 지원 시스템입니다. 상단 네비게이션의 📋 작업내역서를 클릭하세요.

주요 기능 및 사용법

  1. 내역 작성: 접수번호(TR-YYYYMMDD-NNN)는 자동으로 매겨집니다. 아래 항목을 입력합니다.
    • 고객 정보: 고객명, 연락처, 주소, 이메일, 선호 연락 방식(전화/문자/이메일)
    • 장비 정보: 장비 종류(데스크탑/노트북/서버/기타), 제조사/모델명, 일련 번호, 구입일자, 부품 인수(충전기/마우스/케이블/가방/기타)
    • 증상 / 요청 사항
    • 처리 현황: 처리 상태(접수/진단중/수리중/완료/인도완료), 예상/완료일, 담당 기술자, 보증 기간
  2. 진단 및 작업 내역: ＋ 작업 행 추가로 행을 늘리고 작업 내용, 부품/자재, 비용(원)을 입력합니다. 각 행의 ✕로 삭제할 수 있습니다. 비용은 그대로 더해져 합계 금액(부가세 포함)으로 표시됩니다. (공급가액/부가세를 따로 나누지 않습니다.)
  3. 서명: 고객 서명과 담당자 서명 패드에 마우스나 펜, 터치로 서명할 수 있고 '지우기'로 다시 쓸 수 있습니다. 그린 서명은 저장되지 않고 Excel에도 들어가지 않으므로, 서명이 필요하면 저장 전에 인쇄하세요. 저장된 내역을 불러오면 서명란은 비워집니다.
  4. 💾 저장하기 & 깜빡임 중지: 고객명을 입력해야 저장됩니다. 저장하면 서버에 보존되고 상단 📋 작업내역서 버튼의 깜빡임이 멈춥니다. ➕ 새로 작성으로 빈 양식을 엽니다.
  5. 📂 저장된 내역 목록: 검색, 🔄 새로고침, 그리고 행마다 📂 열기 · 📥 Excel · ✕ 삭제를 할 수 있습니다.
  6. 🖨️ 인쇄 / PDF 출력: 버튼 클릭 시 A4 1페이지 규격의 작업내역서 양식으로 브라우저 인쇄 창이 열려 출력 또는 PDF 저장이 가능합니다.
  7. 📥 Excel 다운로드: 작업내역서_{고객명}_{접수번호}.xlsx 파일로 다운로드됩니다.
  8. 🔴 빨간색 [닫기] 버튼: 모달 우측 상단의 선명한 빨간색 버튼으로 작업을 마친 뒤 손쉽게 닫을 수 있습니다.

14. 팝업 계산기 (부가세 역계산)

상단 메뉴의 🧮 계산기를 누르면 견적 창과 분리된 운영체제 독립 창으로 계산기가 팝업됩니다. 창 제목 바를 잡고 보조 모니터나 화면 구석으로 자유롭게 옮겨두고 사용할 수 있습니다.

원클릭 부가세(VAT) 자동 계산

버튼입력된 금액의 성격연산 결과
부가세 역계산 부가세가 포함된 총 입금액/판매가 금액을 1.1로 나누어 공급가액과 부가세(10%)를 분리 산출 (합계가 원단위까지 정확 일치)
부가세 더하기 부가세가 제외된 순수 공급가액 10% 부가세를 가산하여 최종 청구 합계금액을 산출
  • 연산 후 화면에 표시된 공급가액 · 부가세 · 합계 금액 행을 클릭하면 해당 금액이 계산기 입력창으로 즉시 복사되어 후속 계산이 매우 편리합니다.
  • 0, 00, 000 버튼으로 큰 금액을 빠르게 입력할 수 있고, C(초기화) · ⌫(한 글자 지우기) · % 키도 있습니다.
  • 키보드 입력도 됩니다: 숫자 · 넘패드, Enter(계산), Backspace, Delete/C(초기화), Esc(창 닫기).
  • 다른 기기에서 접속해 눌러도 계산기는 서버 PC 화면에 열립니다.

15. 쿠팡 검색과 파트너스 연결

각 견적 카드와 상세 견적서의 🛒 쿠팡검색 버튼을 누르면 해당 모델명 그대로 쿠팡에서 검색합니다. (CPU + 그래픽카드로 검색어를 줄이는 기능은 중고 시세 버튼에만 적용됩니다.)

16. 문제 해결 (FAQ)

현상원인 및 해결 방법
다른 컴퓨터/스마트폰에서 접속이 안 됨 1. 같은 공유기(Wi-Fi/LAN)에 연결되어 있는지 확인하세요.
2. 상단 🌐 네트워크 접속 버튼을 눌러 정확한 IP(예: http://192.168.0.13:8090/)를 확인하세요.
3. 서버 PC의 윈도우 방화벽에서 8090 포트를 허용해 주세요.
노란색 "Apple 공식몰 수집 상태 점검" 상자가 뜸 공식몰 개편이나 접속 실패로 일부를 못 읽은 상태입니다. 먼저 🔄 공홈 실시간 새로고침을 눌러 보고, 계속 뜨면 상자의 내용을 개발자에게 전달하세요. (8번 항목)
Apple 제품 목록에 구형 모델이 보이거나 갱신이 필요함 애플스토어 카테고리 우측 상단의 🔄 공홈 실시간 새로고침 버튼을 클릭하세요. 기존 캐시를 완전히 파기하고 현재 공식몰 판매 제품으로 100% 덮어씁니다.
견적정보/작업내역서 창을 닫고 싶음 모달 창 우측 상단의 빨간색 [닫기] 버튼을 누르거나 키보드 Esc 키를 누르세요.
견적서 엑셀에 공급자나 고객 정보가 비어 있음 상단 📇 견적 정보 버튼을 눌러 상호 및 대표자 정보를 입력하고 저장한 후 다시 다운로드하세요.
서버가 시작되지 않거나 포트 충돌 발생 시 프로그램 폴더의 stop.bat 을 실행해 기존 프로세스를 정리한 뒤 START.bat 을 다시 실행하세요. 해결되지 않을 경우 force_stop.bat 을 관리자 권한으로 실행합니다.
단가가 - 로 표시되고 합계만 나옴 상단 옵션 바의 💰 버튼이 '단가미표시'로 설정되어 있는 상태입니다. 버튼을 한 번 눌러 초록색 '단가표시'로 전환하세요.
