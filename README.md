# ⚡ 컴퓨존 견적 자동화 & Apple Store 견적 시스템 Ver X.15

컴퓨존(Compuzone) 조립PC 및 Apple Store 공식몰의 실시간 견적을 자동 수집하고, 단가 조절 · 부가세 계산 · 중고 시세 검색 · 네트워크 다중 접속 · 작업내역서 작성 · 8종 Excel 견적서 발행을 지원하는 올인원 업무 솔루션입니다.

---

## 🆕 Ver X.15 주요 신규 기능

1. **🔄 [업데이트] 버튼** — GitHub에 새 버전이 있는지 확인해 팝업으로 알려 주고, 승인하면 내려받은 뒤 재시작 여부를 묻습니다.
2. **✕ [종료] 개선** — 확인 없이 바로 캐시 삭제 → 화면 새로고침 → 서버·포트 정리 → 창 닫기. 견적을 불러오는 중에도 즉시 종료됩니다.
3. **🍎 Mac 실시간 CTO(구성하기)** — 애플 공식몰 '구성하기' 가격으로 메모리·SSD·칩·디스플레이·이더넷·어댑터 옵션을 계산합니다. 칩을 바꾸면 따라 바뀌는 메모리·SSD 최소 사양과 "(선택 시 계산)" 옵션도 공식몰과 똑같이 처리합니다.
4. **📥 CTO 견적 Excel 반영** — 적용한 CTO가 Excel(전체·카드별)에 들어가며, 메모리·SSD·칩은 기본 사양 행이 업그레이드 사양으로 교체됩니다.
5. **📐 Mac 기본 사양 보정** — 구매 페이지에 없는 기본 메모리·SSD를 구성하기 API로 바로잡습니다(예: Mac mini M5 Pro 24GB·512GB).
6. **⚠️ 공식몰 수집 상태 점검** — 애플 페이지 개편·접속 실패·새 제품군을 화면 경고와 로그로 알려 줍니다.
7. **🖼️ 대표 이미지** — 모든 카드에 [이미지] 버튼, 상세 견적서 하단에 원본 페이지 대표 이미지 표시.
8. **💻 노트북 금액대로 찾기 개선** — 노트북 Excel이 노트북 견적으로 나오고, 안내 문구·버튼·옵션 표시가 노트북에 맞게 바뀝니다.
9. **기타** — 폼7·폼8 고정 계좌번호·성경 구절 제거, Esc로 모든 창 닫기, 사용설명서 전면 갱신.

## 🌟 Ver 9.0 주요 기능

1. **🌐 네트워크(LAN IP) 다중 기기 동시 작업 지원**
   - 메인 컴퓨터뿐만 아니라 같은 공유기(Wi-Fi 또는 유선 LAN)에 연결된 사무실/매장의 다른 PC, 노트북, 스마트폰, 태블릿에서 `http://[실행컴_IP]:8090`으로 동시 접속 가능.
   - 상단 메뉴의 `🌐 네트워크 접속 (IP)` 버튼을 클릭하면 접속용 전체 주소가 클립보드에 원클릭 자동 복사됩니다.

2. **🍎 Apple Store 공식몰 100% 실시간 동기화 & 구버전 데이터 완전 정리**
   - 과거 하드코딩 모델 및 이전 스냅샷을 완전히 비우고, 애플 공식 홈페이지(한국)에서 현재 판매 중인 정품 최신 라인업만 실시간 수집 및 노출.
   - 상단 **`[🔄 공홈 실시간 새로고침]`** 버튼으로 언제든 캐시를 100% 파기하고 공홈 데이터를 새로 긁어와 완전 교체 가능.

3. **🔴 다크모드 시인성 강화 — 팝업 모달 내 빨간색 [닫기] 버튼**
   - 어두운 배경에서 찾기 어렵던 우측 상단 `✕` 대신, **견적 정보** 및 **작업내역서** 모달 헤더에 선명한 빨간색 **[닫기]** 버튼을 배치하여 직관적으로 닫을 수 있습니다.

4. **✨ 견적 정보 & 작업내역서 저장 시 깜빡임(Pulse) 자동 멈춤**
   - 앱 최초 실행 시 입력을 유도하기 위해 깜빡이던 상단 버튼이, 정보를 한 번이라도 입력하고 저장하면 즉시 깜빡임을 멈추고 일반 버튼으로 고정됩니다.

5. **⚡ 번개장터 · 🟢 중고나라 원클릭 시세 검색**
   - 각 견적 카드마다 중고 거래 바로가기 버튼 탑재.
   - 조립PC는 컴퓨존 모델명 대신 핵심 부품인 **CPU + 그래픽카드**(예: `7800X3D RTX 4070 SUPER`)로 자동 변환하여 실제 거래 매물 검색.

## 🚀 빠른 시작 가이드

### 1. 프로그램 실행
- `START.bat` 을 더블클릭합니다. 처음 실행하는 PC라면 필요한 패키지를 자동으로 설치(`install.bat`)한 뒤 시작합니다.
- 백엔드 서버(FastAPI/Uvicorn, 포트 `8090`)가 구동되며, 주소창 없는 깔끔한 독립 브라우저 창(App 모드)이 자동 실행됩니다.
- 같은 네트워크의 다른 기기에서는 `http://[서버PC_IP]:8090/` 으로 접속할 수 있습니다.

### 2. 프로그램 종료
- 화면 우측 상단의 **✕ 종료** 버튼을 누르면 서버 프로세스 종료, 8090 포트 반환, 임시 캐시 정리, 앱 창 닫기가 일괄 수행됩니다.
- 비정상 종료 시 `stop.bat` 또는 `force_stop.bat` 을 실행하세요.

## 📋 주요 기능 안내

### 1. 컴퓨존 조립PC 견적
- **AI PC 견적**: AI 데스크탑 기획전 상품 라인업 실시간 수집.
- **프리미엄PC / 아이웍스PC / 추천조립PC**: 실시간 BOM 부품 슬롯 및 최신 판매가 수집.
- **🎮 게임으로 PC 찾기**: 게임(최대 4개)과 모니터 해상도(FHD/QHD/4K)를 선택하여 최적 PC 추천.
- **💵 금액대로 찾기**: 예산 범위(만원 단위)를 입력하여 전 카테고리 실시간 검색.

### 2. Apple Store 견적 및 CTO
- MacBook, iMac, Mac mini, Mac Studio, iPad & iPhone, Studio Display 등 공식몰 판매 제품 실시간 수집.
- **⚙️ 사양 CTO 수정**: CPU/GPU 코어, RAM 용량, SSD 용량, Nano-texture 글래스, AppleCare+ 보증 연장 등을 실시간 추가 및 총액 자동 계산.
- **정품 단가 그대로 적용**: 올림이나 반올림 로직 없이 애플 공식 홈페이지의 실제 판매가(원단위) 그대로 화면 및 Excel 견적서에 정확히 반영.

### 3. 견적 옵션 및 마진 제어
- **옵션 토글**: 모니터, 무선키보드마우스, 메모리 32GB(AI PC), 초기 세팅비(0원이면 별도청구).
- **💳 마진 원클릭 순환**: `C(30% 소비자견적)` → `25%` → `20%` → `15%` → `10%` → `0%(원가)` 순으로 순환 변경.
- **단가 비례 분배**: 마진율 변경 시 모든 부품의 단가에 동일하게 비례 분배되어 단가 총합과 견적 합계가 일치.
- **💰 단가표시 / 단가미표시**: 고객에게 개별 부품 단가를 감추고 합계금액만 제안하고 싶을 때 원클릭 전환.

### 4. Excel 견적서 발행 (전문 서식 8종)
- **전체 다운로드**: 상단 `📥 Excel 다운로드` (모든 견적을 1개 파일로 일괄 저장).
- **단일 다운로드**: 카드별 `📥 엑셀 견적서` (해당 제품 1건만 저장).
- **8종 디자인 시트**:
  - `견적요약` (비교 제안 마스터표)
  - `폼1 (표준)` (B2B 표준 견적서, 공급자/수급자 직인란)
  - `폼2 (인보이스)` (영문 모던 INVOICE 스타일)
  - `폼3 (보고서)` (결재/보고용 총액 강조 요약형)
  - `폼4 (명세서)` (부품 엔지니어링 기술 명세서형)
  - `폼5 (리테일)` (매장 즉시 발송용 영수증 스타일)
  - `폼6 (조립PC)` (부품별 A/S 기간 및 4대 소비자 유의사항 명시)
  - `폼7 (데스크탑)` (제품 상세 SPEC 표 및 고객 발주확인란 구비)
  - `폼8 (클래식)` (관공서/기업 납품 세로형 등록번호 전통 서식)
- 모든 시트는 **A4 세로 1페이지 폭 맞춤(Fit to Page)** 및 여백 15mm가 사전 세팅되어 인쇄 시 잘림 방지.

### 5. 컴퓨터 작업내역서 (출장/수리)
- 고객 정보, 장비 사양, 접수 증상 및 점검 소견 작성.
- 작업/부품 비용 입력 시 공급가액, 부가세, 청구합계 자동 연산.
- 현장 전자 서명 패드 내장.
- **A4 1페이지 규격 종이 인쇄 / PDF 출력**, 서버 DB 저장 및 이력 관리, Excel 다운로드 지원.

### 6. 독립 팝업 계산기
- 상단 `🧮 계산기` 클릭 시 브라우저 밖으로 띄울 수 있는 독립 팝업 창 제공.
- **부가세 역계산** (합계금액에서 공급가액과 부가세 분리) 및 **부가세 더하기** 지원.
- 계산된 금액 행 클릭 시 계산기로 금액 즉시 복사.

## 🛠️ 기술 스택 및 구조

- **Backend**: Python 3.12+ / FastAPI / Uvicorn (포트 `8090`)
- **Frontend**: HTML5, Vanilla CSS3 / JavaScript (No external framework dependencies)
- **Scraper**: urllib / BeautifulSoup4 (컴퓨존 실시간 상품 페이지 & Apple 공식 스토어 라이브 동기화)
- **Excel Engine**: openpyxl (A4 자동 핏, 스타일링, 다중 서식 시트 생성)
- **Network**: `0.0.0.0` 바인딩을 통한 로컬 및 LAN IP 다중 클라이언트 지원
